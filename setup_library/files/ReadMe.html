If your reading this file its because you have inserted a fresh usb stick.

The drive is formated exfat and has the label of “Library_USB”


The drive has 3 folders:

  • library

    • This is where you put folders and files media etc

  • html

    • The system makes a dynamic web page on boot nothing for you here

  • wiki

    • This is where you put your wiki files depending on the size of your usb stick

    • see below a list of wiki’s you can download and put on this usb the zim file is read and an xml file is created. If you put a new wiki file you must delete the xml file or it won’t add



To add data power off your Library and insert the usb stick in your computer and put the files you want onto it. The drive is formatted correctly at that point because your reading this file.
